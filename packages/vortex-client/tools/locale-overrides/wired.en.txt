# The Wired Creator Tools texts, lifted out of the embedded asset so they can be edited.
#
# Why this file exists
# --------------------
# These strings do NOT come from `external_flash_texts`. They come from the embedded
# `default_localizations` asset declared by
# `sources/WIN63-202607011411-782849652/src/binaryData/HabboLocalizationCom.as` (embed seq 2947),
# parsed by `HabboLocalizationManager.loadDefaultEmbedLocalizations()`. That embed ships inside
# the client bundle, is English-only (none of the twelve per-language embeds carries a single
# `wired*` key), and `packages/vortex-client/src/assets/` is gitignored and regenerated by the
# asset importer - so editing it there is both invisible to git and lost on the next import.
#
# The 198 keys below are exactly the `wired*` keys the embed is the ONLY source for. Load order
# is: global embed -> per-language embed -> external texts after auth, so an external key wins.
# Routing them through the external texts makes them editable server-side (rebranding, wording,
# a later translation) with no change to the bundle and no change to what renders today.
#
# Values are verbatim from the embed - this file is a passthrough, not a rewrite. Placeholders
# (`%amount%`), `${...}` references, `<font>` markup and literal `\n` are preserved as-is.
#
# Applied by:
#   node packages/vortex-client/tools/build-gamedata-locale.mjs --overrides=packages/vortex-client/tools/locale-overrides/wired.en.txt --write --out=<gamedata dir>
#
# Note: `wiredmenu.settings.room_state.reload` is declared twice in the embed ("Save & reload"
# then "Reload"); the kv parser lets the last one win, so only that value appears here.
