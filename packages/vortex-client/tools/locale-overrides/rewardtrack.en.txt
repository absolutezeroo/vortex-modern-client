# Reward-track texts that upstream does not have.
#
# Why this file exists
# --------------------
# `sources/external_flash_texts.txt` carries 156 `reward_track.*` keys and every one of them
# belongs to `introduction`, the single permanent track the 2026 client shipped with. Two kinds of
# key are therefore missing and always will be:
#
#   - the season picker's tooltip, which is Vortex's own — AS3 has no picker because it has no
#     second track to switch to (see RewardTrackHeaderView.initializeSeasonSelect);
#   - the name/desc/info of any track this hotel defines itself. A track's texts are looked up as
#     `reward_track.<track_id>.name` / `.desc` / `.info`, so a track seeded in `reward_tracks`
#     with no matching keys renders its own key strings — and because `track_title_txt` is
#     multiline word-wrapped 18px bold, a 35-character key wraps to three lines and overruns the
#     header.
#
# `sequence_showcase` below is the track from `scripts/sql/reward_track_sequence_showcase.sql` in
# the emulator. Copy that block for each new season: the ids have to match `reward_tracks.track_id`.
#
# Apply them to a deployed gamedata file with:
#
#   node packages/vortex-client/tools/build-gamedata-locale.mjs \
#        --overrides=packages/vortex-client/tools/locale-overrides/rewardtrack.en.txt \
#        --merge-into=C:/Laragon/www/vortex-assets/gamedata/external_flash_texts.json --write
